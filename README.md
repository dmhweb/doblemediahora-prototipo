# Prototipo Rediseño - Doble Media Hora

Prototipo funcional HTML del rediseño propuesto para [doblemediahora.ar](https://doblemediahora.ar/).

## Cómo verlo (sin descargar)

### Opción más fácil
Abrí este link directamente en el navegador:

**https://htmlpreview.github.io/?https://github.com/dmhweb/doblemediahora-prototipo/blob/main/index.html**

### Otras opciones
- Archivo raw: https://raw.githubusercontent.com/dmhweb/doblemediahora-prototipo/main/index.html  
  (hacé clic derecho → Guardar como… → index.html → abrir con el navegador)
- Repositorio: https://github.com/dmhweb/doblemediahora-prototipo

## Qué incluye el prototipo
- Diseño **mobile-first** y responsive
- **Selector de localidad** (Reconquista, Avellaneda, Malabrigo, Romang, Regionales)
- **Modo oscuro** (ícono sol/luna)
- Buscador con estilo **IA**
- Navegación inferior tipo **PWA / app**
- Secciones por localidad + Agenda de Eventos
- Cards limpias, badges de localidad, tiempo de lectura

Creado para el proyecto de modernización de Doble Media Hora (Pepe Sánchez).
