## Estructura del prototipo v2 (como la home actual)

1. **Noticia destacada** (grande)
2. **4 noticias al costado**: 2 de Reconquista + 2 de Avellaneda
3. Espacio **publicidad estática** (se mantiene)
4. **Regionales**
5. **Provinciales**
6. **Reproductor DMH TV** (placeholder para link diario automatizable desde WordPress)
7. Espacios para **Google AdSense** + **Meta Ads**
8. **Deportes**
9. **Agenda de Eventos** (nuevo)
10. **+ Noticias / Últimas**
11. Publicidad estática inferior

**Sin sección Policiales** (como pediste).

También incluye:
- Selector de localidad
- Modo oscuro
- Buscador estilo IA
- Navegación inferior tipo PWA
- Diseño mobile-first

Creado para el proyecto de modernización de Doble Media Hora.
