# Tema WordPress - Doble Media Hora

Esqueleto del tema custom (Fase 1).

## Cómo instalar

1. Descargá el archivo `doblemediahora-theme.zip`
2. En WordPress: Apariencia → Temas → Añadir nuevo → Subir tema
3. Activá el tema "Doble Media Hora"

## Archivos incluidos

- `style.css` – Estilos mobile-first + modo oscuro
- `functions.php` – Setup, helpers, widget areas
- `header.php` / `footer.php`
- `front-page.php` – Home con la estructura exacta pedida
- `assets/js/main.js` – Modo oscuro + selector de localidad
